# Marketing Analytics Decision Lab

A graduate marketing-analytics portfolio covering statistical inference, diffusion, segmentation, experimental analysis, regression, factor analysis, conjoint/choice modeling, and customer lifetime value.

## Portfolio story
**Market question → statistical method → validated result → managerial interpretation**

## Method library
Chi-square and proportion testing • Bass diffusion • clustering • factorial ANOVA • test-market analysis • logistic regression • factor analysis/reliability • conjoint analysis • choice/share simulation • customer lifetime value

## Source-derived decision evidence
- Chi-square: **χ²=7.576, p=.005916**
- Proportion test: **z=-5.59, p≈1.13×10⁻⁸**
- Bass diffusion: **p=.0204, q=.3752**
- Segmentation: **3 clusters**; primary segment **171/393**
- Factorial ANOVA: advertising significant; coupons not significant in the analyzed exercise
- Logistic model: Strength **p=.021**; modeled probability approximately **66%→86%** as Strength moved 3→5
- Two-factor solution: approximately **75% variance**; reliability α≈**.861/.795**
- Conjoint: price **36.9%**, calories **33.2%**, brand **18.1%**, packaging **11.7%**
- Sports package: ticket location **39.5%**, ticket price **37.6%**; recommended option projected about **$3.4M vs $2.6M**
- LTV: baseline **2.5**; approximately **87.5% retention** required to double to 5 from 75%

## Evidence boundary
Original analyses used tools including Excel/SPSS. Course datasets and uncertain source files are not redistributed. This repository preserves traceable results and methodology without pretending the original data is public.
